새 회원이 오셨을 때

회원 등록하기

  1. 위쪽 회원 을 누르세요.
  2. 초록색 + 새 회원 등록 을 누르세요.
  3. 이름과 휴대폰 번호 뒷자리 4자리를 적으세요.
  4. 연락할 번호도 꼭 적으세요. 휴대폰 번호를 010부터 전부 적고, 휴대폰이 없는 분은 가족 번호를 비상연락처에 적어요. 번호가 없으면 저장이 안 돼요.
  5. 종이 개인정보 동의서에 서명을 받고, 받은 항목에 체크하세요.
  6. 저장 을 누르면 끝이에요. 그분은 바로 출석할 수 있어요.

번호 뒷자리와 이름이 똑같은 분이 이미 있으면 알림이 떠요. 그때는 두 분 모두 구분 메모에 "1948년생"처럼 적어 주세요.

회원이 그만두셨을 때

출석 중지하기

  1. 회원 에서 그분 이름을 찾으세요. 찾는 칸에 이름을 적어도 돼요.
  2. 이름 아래 출석 중지 를 누르고 확인을 누르세요.

지난 출석 기록은 지워지지 않아요. 다시 오시면 다시 출석 가능 을 누르면 돼요.

오늘 누가 왔는지 궁금할 때

오늘 출석 보기

오늘 을 누르면 오늘 오신 분과 시간이 나와요. 방금 오신 분이 안 보이면 새로고침 을 누르세요.

잘못 누른 출석이 있으면 그 이름 옆 출석 취소 를 누르세요. 기록은 따로 남아요.

매주 토요일 아침 8시쯤

메일로 오는 "연락해 보세요" 명단

Gmail에 [힐링엔젤스 경기광주점] 주간 출석 리포트 메일이 와요. 맨 위 숫자는 지난 일주일 동안 오신 분 수예요. 그 아래 "연락해 보세요" 명단만 보시면 돼요.

  • 요즘 안 보이세요꾸준히 오시다가 한동안 안 오신 분이에요. 안부 전화를 드려 보세요.
  • 출석이 줄었어요예전보다 많이 덜 오시는 분이에요. 불편한 점이 없으신지 여쭤보세요.
  • 새로 오셨어요이번 주에 처음 오신 분이에요. 환영 인사를 건네 보세요.
  • 등록만 하고 안 오셨어요등록하고 2주가 지났는데 아직 한 번도 안 오신 분이에요.

이름 옆 전화 나 비상연락처 를 누르면 바로 전화가 걸려요. "번호 없음"이 뜬 분은 회원 에서 고치기 를 눌러 번호를 넣어 주세요.

같은 내용은 기록·통계 맨 위에서도 언제든 볼 수 있어요.

회원분이 "제 이름이 안 나와요" 하실 때

번호 확인하기

  1. 회원 에서 그분 이름을 찾으세요.
  2. "번호 뒷자리"가 그분 휴대폰 번호 끝 4자리와 같은지 보세요.
  3. 다르면 고치기 를 눌러 번호를 바로잡고 저장 을 누르세요.

목록에 아예 안 보이면 "출석 중지된 회원도 보기"에 체크해 보세요. 거기 있으면 다시 출석 가능 을 누르면 돼요.
